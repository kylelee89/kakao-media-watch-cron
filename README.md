# kakao-media-watch-cron

카카오 인적분할 언론보도 모니터링 대시보드의 **수집 스케줄러**입니다.

10분마다 대시보드의 수집 API 를 호출해서, 아무도 페이지를 보고 있지 않아도
새 기사가 계속 쌓이도록 합니다. Vercel Hobby 플랜은 크론을 하루 1회만
허용하기 때문에 이 저장소가 그 역할을 대신합니다.

이 저장소에는 코드도 수집 데이터도 없습니다. 호출 대상 주소는
저장소 시크릿 `WATCH_URL` 에 있어서 공개 저장소여도 드러나지 않습니다.

- 실행 이력: Actions 탭
- 수동 실행: Actions > 카카오 언론보도 수집 트리거 > Run workflow
